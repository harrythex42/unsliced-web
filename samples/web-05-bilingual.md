# 双语交付摘要 / Bilingual delivery notes

本期的目标是让首次使用的读者能在两分钟内找到入口和借还窗口。The goal is to help a first-time visitor find the entrance and the checkout desk in two minutes.

## 状态 / Current status

**Ready / 已就绪**：路标和开放时间已更新。The signs and the opening hours have been updated.

**In review / 待复查**：轮椅通道的转角处需检查。The turn in the wheelchair access route still needs an inspection.

## 术语 / Terms

| 中文 | English | 使用场景 |
| --- | --- | --- |
| 值班交接 | shift handover | 每日闭馆时使用 |
| 暂停服务 | temporarily unavailable | 店内外公告都要同步 |
| 图书归还处 | returns desk | 不要与咨询窗口混写 |
| 复查人 | second reviewer | 确认数据没有录入错误 |

## 标点与形似字

括号（全角）与 (half-width) 分开核对；破折号 — em dash；范围 08:00–18:30；型号：A-17 / B-09；百分比：31.5%。

「口 / ⼝」「高 / ⾼」「子 / ⼦」包括字形相似、编码不同的字符。选择并复制时，应能保留差异。

> Please keep both languages in the same handover note. 请在交接记录里保留两种语言。

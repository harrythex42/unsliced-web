# 线上手动检查 · Chrome · 约 1 分钟

在 Chrome 打开 **<https://harrythex42.github.io/unsliced-web/>**。右上角选「简体中文」，点「试试示例」。等出现页数后，点「存为 PDF」。目标选「另存为 PDF」，纸张 A4，比例 100%，关闭页眉和页脚。保存后打开 PDF；需要保留结果时，可以放在 `output/web-live/manual/`。

每项只答 **是 / 否**：

| 问题 | 正常应该看到什么 |
| --- | --- |
| 页面能打开，且点示例后自动出现预览吗？ | 中文标题正常显示，预览有两页。 |
| 建议的 PDF 文件名正确吗？ | 建议名称是「阅读空间项目周报」，不是 `Unsliced`。 |
| PDF 的两页跟预览一样吗？ | 两页分别从「阅读空间项目周报」和「下周安排」开始，没有空白页、网址或日期。 |
| PDF 能搜索和复制中文吗？ | 用 `⌘F`（Windows 用 `Ctrl+F`）找到「周报归档」，复制后仍然是这四个字。 |
